Forja turns a reference image into a GLB with a low-poly mesh, a base color texture, baked normal and ambient occlusion maps, and LODs. It runs open models on your own GPU, on another computer on your network, or on a cloud you configure.

How it works

Eight stages, from picture to file

A job is a pipeline of stages. The untextured mesh shows in the viewer as soon as the shape is done, so you can judge it before the paint finishes. CPU stages of one job overlap GPU stages of the next, so the GPU is never left waiting.

  1. 01

    Cut out

    BiRefNet removes the background from your picture.

  2. 02

    Frame

    The subject is centered and framed at 1024 pixels.

  3. 03

    Shape

    TripoSG or Hunyuan3D-2mv generates the mesh, from one view or several.

  4. 04

    Clean up

    The generated mesh is cleaned up before anything is built on it.

  5. 05

    Low-poly

    The mesh is reduced to the preset's triangle budget, or rebuilt from quads in Blender.

  6. 06

    Paint

    Hunyuan3D-2 Paint unwraps the mesh and paints its base color.

  7. 07

    Bake

    High-poly detail is baked into normal and ambient occlusion maps.

  8. 08

    LODs and export

    Two LODs, at 50% and 25%, then one GLB.

Optional switches per job: match the reference colors, quad remesh and Smart UV Project through Blender, paint a denser mesh, and rig the character with UniRig or SkinTokens.

Presets

Four budgets, one drop

A preset names the stages and their budgets, never a model. Change any value for one job, for every job, or write your own preset in YAML and keep it in your project's repository.

Where it runs

Your GPU first. Any other GPU when you say so.

The app and the CLI talk to one local service, the core. It plans each job and sends stage batches to whichever engine should run them. Files are addressed by their hash, so nothing is uploaded twice.

This computer

Hardware is detected at run time: CUDA, MPS, ROCm or CPU. Each model is marked runnable, runnable with offload, or remote only. Built and tested on a 12 GB RTX 4070 Ti.

A computer on your network

Share a GPU with another machine by a six-digit pairing code. A Mac can run a shape on its own GPU and send the rest to the PC in the next room.

A cloud you configure

RunPod, Modal, a ComfyUI bridge, or fal.ai's hosted models. Route by price or by speed, see an estimate before a job runs, and set a hard spending limit.

On the bench

Built for the asset, not the demo

A library that exports

GLB, FBX, OBJ, glTF, USDZ, STL and .blend. Open an asset in Blender, or drag it straight into another app.

Rigged characters

UniRig or SkinTokens adds a skeleton and skin weights, with standard humanoid bone names that game engines retarget to, kept through the LODs and exports.

More than one view

Add side and back views, or drop a turnaround sheet and let Forja split it into views.

Blender in the pipeline

Quad remesh, Smart UV Project, and a bake in MikkTSpace tangents, as stages like any other.

Pluggable models

The core knows stage types, never vendors. A model is a manifest plus an adapter, each family in its own Python environment.

Measured, not promised

forja bench is a benchmark suite with a regression check. A change that is more than 10% slower fails CI.

Command line

Everything the app does, from a terminal

Every feature lives in both the desktop app and the forja command, through the same local service. Script a batch overnight, then review the results in the library in the morning.

Read the CLI guide

forja
# install the models the presets need, then test them
$ forja setup

# one image, the default preset
$ forja generate chest.png

# a hero character, quad-remeshed and rigged
$ forja generate knight.png --preset hero-character --with remesh --with rig

# see the plan without queueing the job
$ forja generate chest.png --dry-run

Get started

Light the forge

You need Git, Go, uv, Node.js 22 or newer with pnpm 10, and make. On first run the Models screen checks your computer, shows each model's license, installs the models and runs a test. Then drop an image on Generate.

Download Install guide

Pre-1.0. Forja works today on Windows with an NVIDIA GPU. The macOS and Linux packages are built but not yet tested, and things will break before 1.0.

sh
$ git clone https://github.com/PauloRTesJr/forja.git
$ cd forja
$ make setup      # Python, Go and Node dependencies
$ make desktop    # builds the core and starts the app

# no GPU? deterministic stand-ins run the whole pipeline
$ forja config set models.stubs=true
